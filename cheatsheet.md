## 2. Numbers and algebra

- Order of operations: parentheses, exponents, multiply and divide left to right, add and subtract left to right
- a^m a^n = a^(m+n)
- a^m / a^n = a^(m-n)
- (a^m)^n = a^(mn)
- a^0 = 1, a not 0
- a^(-n) = 1/a^n
- a^(m/n) = nth root of a^m
- log_b(xy) = log_b x + log_b y
- log_b(x/y) = log_b x - log_b y
- log_b(x^k) = k log_b x
- log_b x = log x / log b
- x = (-b +/- root(b^2 - 4ac)) / (2a)
- D = b^2 - 4ac
- D > 0 two real roots, D = 0 one real root, D < 0 no real root
- Sum of roots r1 + r2 = -b/a
- Product of roots r1 r2 = c/a
- System: scale and add to cancel a variable, or substitute
- |x| < a means -a < x < a
- |x| > a means x < -a or x > a
- A negative multiplier reverses the inequality sign
- part = rate x base
- Percent change = (new - old) / old x 100
- a/b = c/d gives ad = bc

## 3. Geometry

- Straight line 180 degrees, full turn 360 degrees
- Parallel lines: alternate interior and corresponding equal, co-interior supplementary
- Triangle angles sum to 180 degrees
- Polygon interior sum = (n - 2) x 180 degrees
- Triangle area = 1/2 x base x height
- Triangle area = 1/2 a b sin C
- Heron: s = (a+b+c)/2, area = root(s(s-a)(s-b)(s-c))
- Similar figures: sides k, areas k^2, volumes k^3
- Right triangle: c^2 = a^2 + b^2
- 45-45-90: x, x, x root(2)
- 30-60-90: x, x root(3), 2x
- Circle: C = 2 pi r
- Circle: A = pi r^2
- Arc: s = r theta, theta in radians
- Sector: A = 1/2 r^2 theta, theta in radians
- Inscribed angle = 1/2 central angle on the same arc
- Cube: V = s^3, SA = 6 s^2
- Prism: V = lwh
- Cylinder: V = pi r^2 h, SA = 2 pi r^2 + 2 pi r h
- Cone: V = 1/3 pi r^2 h
- Sphere: V = 4/3 pi r^3, SA = 4 pi r^2
- Distance = root((x2-x1)^2 + (y2-y1)^2)
- Midpoint = ((x1+x2)/2, (y1+y2)/2)
- Slope m = (y2-y1)/(x2-x1); parallel slopes equal, perpendicular m1 m2 = -1

## 4. Trigonometry

- sin theta = opposite / hypotenuse
- cos theta = adjacent / hypotenuse
- tan theta = opposite / adjacent
- csc = 1/sin, sec = 1/cos, cot = 1/tan
- sin^2 theta + cos^2 theta = 1
- 1 + tan^2 theta = sec^2 theta
- sin(90 - theta) = cos theta

| theta | 0 | 30 | 45 | 60 | 90 |
|---|---|---|---|---|---|
| sin | 0 | 1/2 | root(2)/2 | root(3)/2 | 1 |
| cos | 1 | root(3)/2 | root(2)/2 | 1/2 | 0 |
| tan | 0 | root(3)/3 | 1 | root(3) | undefined |

- Law of sines: a / sin A = b / sin B = c / sin C
- Law of cosines: c^2 = a^2 + b^2 - 2ab cos C
- 180 degrees = pi radians
- Degrees to radians: multiply by pi/180
- Radians to degrees: multiply by 180/pi

## 5. Functions and sequences

- y = f(x - h) + k shifts right h, up k
- y = -f(x) reflects over the x-axis
- y = f(-x) reflects over the y-axis
- Composition: (f o g)(x) = f(g(x))
- Inverse: swap x and y, then solve for y
- Arithmetic term: a_n = a_1 + (n - 1)d
- Arithmetic sum: S_n = n/2 (a_1 + a_n)
- Geometric term: a_n = a_1 r^(n-1)
- Geometric sum: S_n = a_1 (1 - r^n)/(1 - r), r not 1
- Infinite sum: S = a_1/(1 - r), |r| < 1
- Compound interest: A = P(1 + r/n)^(nt)
- Continuous growth: A = P e^(rt)
- Half-life: N = N_0 (1/2)^(t/t_half)

## 6. Statistics and probability

- Mean = sum of x / n
- Median = middle of the ordered list
- Mode = most frequent value
- Variance = sum(x - mean)^2 / N; SD = root(variance)
- Two independent choices: m x n outcomes
- n! = n(n-1)...1 and 0! = 1
- nPr = n! / (n - r)!
- nCr = n! / (r!(n-r)!)
- P(E) = favorable / total
- P(not E) = 1 - P(E)
- P(A or B) = P(A) + P(B) - P(A and B)
- Independent: P(A and B) = P(A) P(B)
- Conditional: P(A|B) = P(A and B) / P(B)
- Expected value: E = sum of x P(x)

## 7. Calculus essentials

- (x^n)' = n x^(n-1)
- (u v)' = u'v + u v'
- (u/v)' = (u'v - u v') / v^2
- (f(g(x)))' = f'(g(x)) g'(x)
- (sin x)' = cos x
- (cos x)' = -sin x
- (e^x)' = e^x
- (ln x)' = 1/x
- Tangent at a: y - f(a) = f'(a)(x - a)
- f' = 0 at a critical point, f'' > 0 minimum, f'' < 0 maximum
- Integral x^n = x^(n+1)/(n+1) + C, n not -1
- Integral 1/x = ln|x| + C
- Integral e^x = e^x + C
- Definite integral from a to b = F(b) - F(a)

## 8. Physics

- Kinematics: v = v_0 + at (m/s)
- Kinematics: x = v_0 t + 1/2 a t^2 (m)
- Kinematics: v^2 = v_0^2 + 2a x
- Gravity: g = 9.8 m/s^2 downward
- Newton: F_net = ma (N)
- Weight: W = mg (N)
- Friction: f = mu N (N)
- Incline: N = mg cos theta, along-slope force = mg sin theta
- Spring: F = kx (N)
- Work: W = F d cos theta (J)
- Kinetic energy: KE = 1/2 m v^2 (J)
- Potential energy: PE = mgh (J)
- Spring energy: PE = 1/2 k x^2 (J)
- Conservation: KE_1 + PE_1 = KE_2 + PE_2 with no friction (J)
- Power: P = W/t = F v (W)
- Momentum: p = mv (kg m/s)
- Impulse: J = F t = change in p (N s)
- Collision: m_1 u_1 + m_2 u_2 = m_1 v_1 + m_2 v_2
- Inelastic: m_1 u_1 + m_2 u_2 = (m_1 + m_2) v'
- Circular: v = 2 pi r / T (m/s)
- Circular: a_c = v^2/r = 4 pi^2 r / T^2 (m/s^2)
- Wave: v = f lambda (m/s)
- Sound in air: v = 343 m/s at 20 C
- Reflection: angle in = angle out
- Snell: n_1 sin theta_1 = n_2 sin theta_2
- Lens and mirror: 1/f = 1/d_o + 1/d_i
- Magnification: m = -d_i/d_o = h_i/h_o
- Ohm: V = IR (V)
- Power: P = IV = I^2 R = V^2/R (W)
- Series: R_eq = R_1 + R_2 + ...
- Parallel: 1/R_eq = 1/R_1 + 1/R_2 + ...
- Heat: Q = mc delta T (J)
- Latent heat: Q = mL (J)
- Kelvin: T(K) = T(C) + 273.15
- Water: c = 4186 J/(kg C), L_fusion = 3.34e5 J/kg

## 9. Chemistry

- n = m/M (mol, M in g/mol)
- N = n x 6.022e23
- Gas at STP: V = 22.4 n (L)
- Molarity: M = mol solute / L solution
- Dilution: M_1 V_1 = M_2 V_2
- Percent by mass = (g solute / g solution) x 100
- Ideal gas: PV = nRT, R = 0.0821 L atm/(mol K)
- Combined: P_1 V_1 / T_1 = P_2 V_2 / T_2
- Dalton: P_total = P_1 + P_2 + ...
- pH = -log[H+]
- pOH = -log[OH-]
- pH + pOH = 14 at 25 C
- [H+] = 10^(-pH)
- K_w = [H+][OH-] = 1.0e-14
- Stoichiometry: balance, convert to mol, mole ratio, convert target
- Radius: increases down a group, decreases across a period
- Ionization energy: increases across, decreases down
- Electronegativity: increases across, decreases down
- Alkane C-C, alkene C=C, alkyne C triple bond
- Alcohol -OH, ether C-O-C, amine -NH_2
- Aldehyde -CHO, ketone C=O internal, acid -COOH
- Ester -COO-, amide -CONH_2, aromatic benzene ring

## 10. Earth and space

- Divergent: plates separate, mid-ocean ridge, new crust, shallow quakes
- Convergent: plates collide, trench, subduction, volcanoes, deep quakes
- Transform: plates slide, shallow quakes, no volcanoes
- Igneous: from magma or lava, intrusive or extrusive
- Sedimentary: layered, compaction and cementation, fossils
- Metamorphic: heat and pressure, foliation
- Troposphere: weather, temperature falls with height
- Stratosphere: ozone layer, temperature rises with height
- Mesosphere: coldest layer, meteors burn
- Thermosphere and exosphere: temperature rises, aurora, satellites
- Moon: new, waxing crescent, first quarter, waxing gibbous, full, waning gibbous, last quarter, waning crescent
- Solar eclipse: new moon, Moon between Sun and Earth
- Lunar eclipse: full moon, Earth between Sun and Moon
- No monthly eclipse because the Moon orbit tilts about 5 degrees
- Kepler 3: T^2 proportional to a^3; T in years and a in AU gives T^2 = a^3
- 1 light-year = 9.46e12 km
- Philippines: on the Pacific Ring of Fire, frequent quakes and volcanoes
- Philippines: typhoon season June to November, about 20 cyclones enter PAR per year

## 11. Abstract reasoning rules

- Meshed gears turn in opposite directions
- Chain or belt drive without twist turns the same direction
- Gear speed ratio: omega_out / omega_in = N_in / N_out
- Gear torque ratio: tau_out / tau_in = N_out / N_in
- Pulley MA = number of rope segments holding the movable load
- Fixed pulley MA = 1, movable pulley MA = 2
- Lever class 1: fulcrum between load and effort
- Lever class 2: load between fulcrum and effort, MA > 1
- Lever class 3: effort between fulcrum and load, MA < 1
- Moment balance: F_1 d_1 = F_2 d_2 about the fulcrum
- Inclined plane MA = length / height
- Series: one path, same current, voltage divides in ratio of R
- Parallel: same voltage, current divides in inverse ratio of R
- Cube net: faces in a row with one face between are opposite
- Rotation keeps handedness, mirror reverses it
- Paper fold: holes = punches x layers pierced
- Number series order: differences, then ratios, then squares or cubes, then two interleaved sequences
- Differences of differences constant means a quadratic pattern
- Letter series: convert to numbers, A = 1 to Z = 26, then treat as a number series
- Coding: shift = coded letter position minus plain letter position, checked on every letter
- Odd one out: name the shared property first, then test each option against it

- Budget 60 percent of the time on pass 1, the rest on flagged items
- Answer sheet: one letter per number, check numbering, erase fully
- Fill every item when wrong answers are not penalized. Read the cover page first.
